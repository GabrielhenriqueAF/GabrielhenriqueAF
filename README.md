## No que estou trabalhando

Nas últimas semanas tenho contribuído de forma constante em uma plataforma web em produção, com dezenas de pull requests incorporados e participação nas revisões de código do time.

O código é privado, então não mostro detalhes por aqui. De forma geral, o trabalho envolve:

- **Back-end:** deixar o sistema mais resistente a falhas, com tempos limite, novas tentativas e respostas de erro adequadas

- **Qualidade:** testes automatizados, correção de bugs e revisão de código

## Projeto pessoal

### [Daymint (Rotina Gabriel)](https://github.com/GabrielhenriqueAF/Daymint)

Aplicativo desktop que criei para organizar minha semana e acompanhar os estudos.

- Planeja os blocos da semana e registra o horário real em que cada atividade foi feita
- Mostra gráficos usando apenas as horas concluídas
- Sincroniza com um calendário separado no Google Agenda
- Guarda os dados em um banco SQLite local, com backup diário

`Electron` · `JavaScript` · `SQLite`
